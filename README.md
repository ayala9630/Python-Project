## 🎨 מה זה TaskMaster?

TaskMaster הוא יישום אינטרנט לניהול משימות ועבודת צוות. אפשר ליצור צוותים, להוסיף משימות עם תיאור ותאריך יעד, לשייך משימה לעצמכם ולעקוב אחר ההתקדמות שלה — **חדשה**, **פעילה** ועד **הושלמה**.

האפליקציה כוללת הרשמה והתחברות, פרופיל אישי, ניהול משימות לפי תפקיד וממשק כהה עם צבעוניות והדגשות מדורגות. הממשק מוצג בעברית ובכיווניות מימין לשמאל.

## 🚀 מה אפשר לעשות?

- 👥 **לנהל צוותים ועובדים** — לשייך עובדים לצוותים ולנהל את החברות בהם.
- 📝 **לעבוד עם לוח משימות** — לראות משימות, צוות משויך, תאריך יעד, סטטוס ועובד אחראי.
- 🔎 **לסנן בקלות** — לסנן את הלוח לפי עובד ולפי סטטוס.
- ✅ **לעקוב אחר התקדמות** — עובדים יכולים לקחת משימות זמינות בצוות שלהם ולסמן את המשימות שלהם כהושלמו.
- 🛠️ **לנהל משימות וצוותים** — מנהלים יכולים ליצור משימות; מנהלי־על יכולים גם ליצור צוותים.
- 🔐 **לנהל חשבון אישי** — להירשם, להתחבר ולעדכן פרטים אישיים ומקצועיים.
- 🌙 **להשתמש בממשק כהה ונגיש** — עיצוב צבעוני עם תמיכה בעברית ובכיווניות מימין לשמאל.

### 🧭 שלבי המשימה

| סטטוס | משמעות |
|:--|:--|
| ⚪ **חדשה** | ממתינה לעובד מהצוות שלה שייקח אותה. |
| 🔵 **פעילה** | עובד לקח אחריות על המשימה ויכול להשלים אותה. |
| 🟢 **הושלמה** | העובד האחראי סיים את המשימה. |

### 🪪 תפקידים באפליקציה

| תפקיד | הרשאות עיקריות |
|:--|:--|
| **עובד** | צפייה במשימות הצוות, לקיחת משימות זמינות והשלמת משימות פעילות ששויכו אליו. |
| **מנהל** | ניהול משימות של הצוות שלו. |
| **מנהל־על** | צפייה במשימות מכל הצוותים, ניהול משימות ויצירת צוותים. |

> **חשוב:** אלה תפקידים של TaskMaster הנשמרים בפרופיל העובד. הם נפרדים מהרשאות הצוות המובנות של Django, כמו `staff` ו־`superuser`.

## 🧰 טכנולוגיות

- **Python 3.12 ומעלה**
- **Django 6.x**
- **SQLite** כמסד הנתונים המקומי כברירת מחדל
- תבניות Django ו־CSS מותאם אישית

## ⚡ הפעלה מקומית

### 1. הורדת הפרויקט

שכפלו את המאגר ופתחו מסוף בתיקיית הפרויקט — התיקייה שמכילה את `manage.py`.

### 2. יצירת סביבה וירטואלית והפעלתה

**Windows PowerShell**

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. התקנת Django

כרגע אין במאגר קובץ `requirements.txt`. התקינו את גרסת Django שבה הפרויקט משתמש:

```bash
python -m pip install "Django>=6.0,<7.0"
```

### 4. הכנת מסד הנתונים והפעלת השרת

```bash
python manage.py migrate
python manage.py runserver
```

פתחו בדפדפן את **http://127.0.0.1:8000/**.

## 🗺️ עמודים מרכזיים

| עמוד | כתובת |
|:--|:--|
| 🏠 דף הבית | `/` |
| 🔑 התחברות | `/app1/login/` |
| ✨ הרשמה | `/app1/register/` |
| 📋 לוח המשימות | `/app1/all_tasks/` |
| ⚙️ ממשק הניהול של Django | `/admin/` |

ליצירת חשבון מנהל עבור ממשק הניהול של Django, הריצו:

```bash
python manage.py createsuperuser
```

משתמשים חדשים מקבלים בתחילה את תפקיד **עובד**. כדי להשתמש בלוח המשימות של הצוות, השלימו את פרטי הפרופיל ובחרו תפקיד וצוות מתאימים. חשבון `superuser` של Django **לא** מקבל אוטומטית את תפקיד **מנהל־על** של TaskMaster.

```text
.

├── task_managment_app1/           # האפליקציה: מודלים, טפסים, תצוגות וכתובות

│   └── templates/task_managment_app1/
├── templates/                     # תבנית משותפת ודף הבית
├── static/                        # CSS, לוגו, סמל ותמונות
├── db.sqlite3                     # מסד הנתונים המקומי של SQLite
└── manage.py                      # כלי שורת הפקודה של Django
```

## 🧪 בדיקות

להפעלת בדיקות Django מתיקיית הפרויקט הראשית:

```bash

```
